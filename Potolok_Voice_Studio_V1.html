1. Голос с микрофона

Нет записи

Для записи в браузере нужен HTTPS или localhost. На Android разреши доступ к микрофону.

Эффекты меняют высоту голоса вместе со скоростью. Реалистичный акцент — следующий этап с ИИ.

2. Фоновая музыка

Мелодии создаются прямо в редакторе и не используют чужие музыкальные записи.

3. Звуковые приколы

Нажми на звук, чтобы прослушать. Кнопка «Добавить» вставит его в конец записи.

Добавлено: 0

4. Видео для Shorts

В первой версии видео можно просматривать рядом с озвучкой. Экспорт готового видео с заменённым звуком добавим отдельно.

5. Готовая озвучка

Готов к работе.

Файл WAV можно вставить в CapCut или другой видеоредактор. При экспорте музыка и эффекты смешиваются с твоим голосом.
